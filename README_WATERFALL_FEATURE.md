## 🎯 功能介绍

为动态列表添加了两种布局模式：

1. **🌊 瀑布流布局**（默认）
   - 双列自适应高度（桌面端）
   - 单列自适应高度（移动端）
   - 类似小红书、Pinterest 的展示效果

2. **📋 列表布局**（原有）
   - 传统的垂直单列布局
   - 清晰的时间线展示

### 核心亮点

- ✨ **一键切换**：顶部导航栏点击即可切换
- 💾 **智能记忆**：自动保存用户选择的布局
- 📱 **响应式设计**：自动适配移动端和桌面端
- 🎨 **视觉优化**：提升空间利用率和视觉效果
- ⚡ **性能优秀**：使用 CSS 实现，性能优异

### 核心代码

#### 状态管理 (echo.ts)

```typescript
// 布局模式状态
const savedLayoutMode = localStg.getItem<'list' | 'waterfall'>('listLayoutMode')
const listLayoutMode = ref<'list' | 'waterfall'>(savedLayoutMode || 'waterfall')

// 监听变化并自动保存
watch(listLayoutMode, (newMode) => {
  localStg.setItem('listLayoutMode', newMode)
})
```

#### 切换按钮 (TheTop.vue)

```vue
<button @click="toggleLayout">
  <WaterfallView v-if="listLayoutMode === 'list'" />
  <ListView v-else />
</button>

<script>
const toggleLayout = () => {
  echoStore.listLayoutMode = 
    echoStore.listLayoutMode === 'list' ? 'waterfall' : 'list'
}
</script>
```

#### 瀑布流样式

```css
.waterfall-container {
  column-count: 1;
  column-gap: 1rem;
}

@media (min-width: 640px) {
  .waterfall-container {
    column-count: 2;
  }
}

.waterfall-item {
  break-inside: avoid;
  margin-bottom: 1rem;
  display: inline-block;
  width: 100%;
}
```

## ❓ 常见问题

### Q: 如何切换布局？

A: 点击顶部导航栏右侧的布局切换按钮即可。

### Q: 默认是什么布局？

A: 默认是瀑布流布局。如需修改，可以在 `web/src/stores/echo.ts` 中修改默认值。

### Q: 布局设置会保存吗？

A: 会的，用户选择的布局会自动保存到 localStorage，刷新页面后会保持。

### Q: 移动端也是双列吗？

A: 不是，移动端（屏幕宽度 < 640px）是单列布局，桌面端才是双列。

### Q: 如何调整列数？

A: 修改 `TheEchos.vue` 和 `TheFilteredEchos.vue` 中的 CSS：

```css
.waterfall-container {
  column-count: 3; /* 改为3列 */
}
```

### Q: 如何调整列间距？

A: 修改 CSS 中的 `column-gap` 值：

```css
.waterfall-container {
  column-gap: 2rem; /* 增加间距 */
}
```

### Q: 切换布局后卡片位置混乱？

A: 这是正常的，因为两种布局的排列逻辑不同。刷新页面即可恢复正常。

### Q: 如何查看当前布局？

A: 在浏览器控制台执行：

```javascript
localStorage.getItem('listLayoutMode')
```

### Q: 如何手动设置布局？

A: 在浏览器控制台执行：

```javascript
// 设置为瀑布流
localStorage.setItem('listLayoutMode', '"waterfall"')

// 设置为列表
localStorage.setItem('listLayoutMode', '"list"')

// 然后刷新页面
location.reload()
```
